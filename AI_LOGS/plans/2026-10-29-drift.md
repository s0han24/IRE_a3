# Plan: drift experiments (SPEC "Experiments on drifted data:", lines 38-64)

Status: approved 2026-10-29. Spec read up to line 64.

## Decisions (human, 2026-10-29)
- Base sizes: **50k** (`--quick`) and **300k** (full), first n SIFT base vectors. Ground
  truth recomputed on that base, as everywhere else ("i just want to check the behaviour").
- Drift settings: mean shift c in {5, 10, 15}; rotation: the same angle for every pair
  (0,1), (2,3), ... in {2, 3, 5} degrees. `--quick`: one setting per kind (c = 10, 5 deg).
- Conditions: clean (re-measured in the same run), stale (clean indexes searched with
  transformed queries: no new builds), rebuilt (base + queries transformed, rebuilt).
- Two recalls per config: (1) vs exact neighbours of the transformed query in the base the
  index was built on; (2) vs exact neighbours of the original query in the original base.
- "Loses its 0.95 config first" = first index with no config at recall (2) >= 0.95 as drift
  strength increases. Recall (1) also reported.
- Stale build time / size = the clean index's numbers, labelled as such.
- Full hyperparameter grid from the Benchmarks section (quick grid in --quick); QPS =
  median of REPEATS = 3; k' = 20; 1 thread for single-query timing.
- README: hypothesis verbatim (compulsory) + one run line; otherwise lean.

Expectation to check, not assume: both drifts preserve L2 distances when applied to base and
queries alike, so rebuilt should reproduce clean up to float / k-means / HNSW-order effects.

## Steps
1. README hypothesis (done) + git commit before any drift code.
2. RED/GREEN `drift.mean_shift(x, c)`: adds c to every coordinate, float32, new array.
3. RED/GREEN `drift.rotate_pairs(x, degrees)`: rotates each (2i, 2i+1) pair; known 2-D case.
4. RED/GREEN property: rotate_pairs preserves pairwise L2 distances (rng data); mean_shift too.
5. WIRING `compute_drift.py`: per kind, clean + settings x {stale, rebuilt}, both recalls,
   latency medians, build time, size -> `results/<mode>/drift_<kind>.json`.
6. Report: per kind a plot (clean / stale / rebuilt per index, at the strongest setting
   and all settings in the tables), all-configs table, recall-drop table + first-to-lose.
7. `run_all.sh` + one README line; run --quick (ask), full (ask), commit.
